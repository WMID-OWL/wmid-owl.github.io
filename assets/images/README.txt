OWL Image Assets

Store site images in the appropriate existing subfolder rather than placing new production assets directly in assets/images.

Current categories include:
- branding
- championships
- events
- factions
- finishers
- innanet
- landscape
- match-cards
- media
- shows
- team-finishers
- teams
- tournaments
- trophy-room
- wrestlers

Use the Control Room upload tools when an asset type has an approved uploader so file naming, optimization, metadata, and database attachment remain consistent.
